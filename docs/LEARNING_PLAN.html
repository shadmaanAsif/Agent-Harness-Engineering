1What you are building, and why

An LLM on its own only turns text into text. It cannot read a file, remember yesterday, or stop itself from doing something risky. The harness is the program you write around it that does those jobs. A working agent is the model plus a harness with seven jobs. Each job gets its own phase.

2How we code along

Every phase uses the same five-stage rhythm, so you always know where you are. I write all the code; you read it, run it, and answer questions. Nothing starts until you say "next".

Stage 1LearnPlain-language idea, new terms, how it works step by step. No code yet.
Stage 2Code alongI build in small steps, each one a readable change. After each I explain it and you can ask questions.
Stage 3Break itI run the failure drill first, so you see the real problem before the fix exists.
Stage 4Prove itI add the fix, then we run tests, the eval and the proof command. You run it too.
Stage 5Check3 to 5 questions. Anything unclear gets re-explained, then I update PROGRESS.md and NOTES.md.
